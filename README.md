# Advanced CSS3 & Responsive Architecture — Portfolio

A responsive personal portfolio built with semantic HTML5, modern CSS architecture, and a small amount of vanilla JavaScript.

## Run it
1. Extract the ZIP file.
2. Open `index.html` in a browser. No installation or build step is needed.
3. Edit the sample name, biography, project descriptions, and email in `index.html` to personalize it.

## Features
- CSS Grid for page-level layouts and project cards.
- Flexbox for navigation, buttons, metadata, and component alignment.
- Mobile-first responsive breakpoints for small phones, tablets, and desktop screens.
- CSS custom properties for colors, surfaces, spacing, and theme values.
- Light/dark theme toggle.
- Mobile navigation menu.
- Semantic sections, accessible labels, skip link, keyboard focus styles, and reduced-motion support.
- Pure HTML, CSS, and JavaScript; no framework or package installation required.

## Suggested internship demo
- Open the page on desktop and resize the browser to show responsive changes.
- Use browser DevTools device toolbar to test phone and tablet widths.
- Toggle the theme to demonstrate the CSS-variable-based light/dark mode.
- Explain how `.hero`, `.skills-grid`, and `.projects-grid` use CSS Grid, while navigation and action groups use Flexbox.
